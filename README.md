# Sistema de Control de Operaciones de Subasta de Ganado

Proyecto de Ingeniería de Software. Sistema desarrollado en Python con interfaz gráfica en Tkinter para gestionar lotes, animales, jornadas, compradores, pujas y facturación en subastas de ganado.

## Tecnologías
- Python 3
- Tkinter
- tkcalendar

## Instalación
1. Instalar Python 3 desde https://www.python.org
2. Instalar la librería de calendario:

        pip install tkcalendar

## Uso
Ejecutar el archivo principal:

        python Sistema_Subasta_Ganado.py
